Troubleshooting
  1. On the thermostat, hold Contractor Info for about 10 seconds.
  2. Set Automation Enable to Automation System, not Aprilaire Cloud. The 8920W installation manual does not list this setting. If you do not see it, this app cannot control that panel.
  3. Give the thermostat a reserved IP address in your router so it does not move.
  4. Quit any other AprilAire automation connection, including Home Assistant. The panel allows only one.
  5. If the panel freezes, switch its breaker off for 30 seconds, then on.
